# Urutan demonstrasi Pinspire

1. Jalankan aplikasi, tekan **Mulai temukan inspirasi**, pilih minat, lalu masuk dengan **Jelajahi dengan akun demo**.
2. Pada **Beranda**, perlihatkan feed masonry. Ubah kategori atau filter **Vibe**. Tekan kartu **The Slow Edit** untuk membuka kurasi Interior + Calm.
3. Buka satu pin. Tekan hati, salin palet warna, lalu tekan **Simpan pin/Tersimpan**. Pilih beberapa board untuk memperlihatkan bahwa pin dapat berada di lebih dari satu board. Tekan **Selesai**.
4. Pada bagian komentar detail pin, tulis komentar. Tunjukkan komentar langsung muncul. Hapus komentar melalui ikon silang bila ingin mendemokan pembatalan.
5. Buka nama kreator dan tekan **Ikuti kreator**. Kembali ke beranda, pilih tab **Mengikuti**. Jika filter terlalu sempit, kembalikan kategori dan Vibe ke **Semua**.
6. Buka **Jelajah**, cari `pantai`. Coba filter Vibe **Fresh** atau urutan **Populer**. Hapus teks untuk melihat riwayat pencarian.
7. Tekan tombol **+ / Buat**. Pilih **Contoh** untuk demonstrasi offline, pilih foto, isi judul, kategori, Vibe, palet, dan board. Tekan **Terbitkan pin**. Foto dari galeri juga dapat digunakan jika izin perangkat tersedia.
8. Pada detail pin buatan sendiri, buka menu tiga titik dan pilih **Edit pin**. Ubah judul, lalu simpan. Menu yang sama menyediakan hapus pin.
9. Buka **Profil** → **Board baru**. Buat board, beri deskripsi, dan aktifkan rahasia jika ingin. Buka board lalu tekan **Tambahkan pin**. Ketuk pin untuk menambahkan atau mengeluarkannya.
10. Pada **Profil**, ganti tab **Tersimpan**, **Dibuat**, dan **Disukai**. Edit profil agar nama atau bio berubah di halaman lain.
11. Buka **Pesan**, pilih percakapan contoh, lalu kirim pesan lokal. Jelaskan bahwa versi front end belum terhubung ke pengguna lain atau server.
12. Buka **Pengaturan**, aktifkan **Hitam pekat**. Keluar lalu masuk kembali untuk memperlihatkan data tetap tersimpan.

Jangan menekan Reset atau Hapus akun ketika ingin mempertahankan data demo. Untuk pengulangan presentasi dari awal, Reset aktivitas mengembalikan board dan percakapan ke data contoh.
